# Free API keys: where to get them

Aqua Code works with many AI providers. Each gives you its own free key, so adding several means more free requests and Aqua switches to the next one when one runs out. In Aqua: **Settings, then paste the key** (you never restart the app). Keys stay on your PC.

Limits change often. Check each provider's page before you rely on a number. Several free tiers log prompts or use them for training: do not send secrets.

| Provider | Free? | Get the key |
|---|---|---|
| **Google Gemini** | Free tier, no card | https://aistudio.google.com/apikey |
| **OpenRouter** (many `:free` models) | Free models, no card | https://openrouter.ai/keys |
| **Groq** (very fast) | Free tier | https://console.groq.com/keys |
| **Cerebras** | Free tier | https://cloud.cerebras.ai |
| **Mistral** | Free "experiment" tier | https://console.mistral.ai/api-keys |
| **NVIDIA NIM** | Free credits / free endpoints | https://build.nvidia.com |
| **GitHub Models** | Free with a GitHub account (use a personal access token) | https://github.com/settings/personal-access-tokens |
| **Cohere** | Free trial key | https://dashboard.cohere.com/api-keys |
| **Hugging Face** | Free inference tier (token) | https://huggingface.co/settings/tokens |
| **Cloudflare Workers AI** | Free daily allowance (token) | https://dash.cloudflare.com/profile/api-tokens |
| **LLM7.io** | Works with no key at all (slow, public prompts); a free token gives more | https://token.llm7.io |
| **DeepSeek** | Pay as you go, very cheap (not free) | https://platform.deepseek.com |

## The big community lists (hundreds of free LLM APIs)

These are the lists the built-in presets come from. When a new free service appears, it shows up here first, and you can add it in Aqua as a custom OpenAI-compatible provider (Settings, Add provider).

- https://github.com/mnfst/awesome-free-llm-apis
- https://github.com/amardeeplakshkar/awesome-free-llm-apis

## Do I need different accounts to get more free usage?

Limits are per account or per key. Using several different providers is the normal, allowed way to get more free usage. Making many accounts at the same provider usually breaks its terms, so do not.
